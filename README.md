# SinabroGameReflex (시나브로 반응속도 테스트)

React, Vite, Tailwind CSS 기반의 반응속도 측정 미니게임 웹 애플리케이션입니다.

## 주요 기능
- **직관적인 게임 플레이**: 대기(빨강/주황) 상태 후 랜덤 시간(1~5초) 뒤 초록색 전환 시 즉시 터치
- **정밀한 밀리초(ms) 반응속도 측정**: `performance.now()` 기반 고정밀 시간 측정
- **거짓 출발(False Start) 방지**: 초록색 전환 전 성급한 터치 감지 및 실패 처리
- **유쾌한 등급 시스템**: 신의 반사신경, 광속의 치타, 바람을 가르는 매, 날렵한 야생마 등
- **로컬 기록 저장**: 기기별 최고 기록 상시 표시 및 측정 히스토리(검색 & 페이지네이션 지원)
- **Vercel 배포 최적화**: SPA 라우팅 및 빠른 번들링 구성
